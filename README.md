

# ⚡ DDoS Tool (Educational Edition)

> ⚠️ For Educational & Authorized Security Testing Only

A simple Python-based network stress testing tool designed for learning purposes and controlled lab environments.

---

## 📌 Disclaimer

This project is strictly for:

* Security research
* Learning about network behavior
* Testing your **own server**
* Authorized penetration testing

Unauthorized use against websites, servers, or networks without permission is illegal.

---

## 🚀 Installation

```bash
rm -rf DDOS
git clone --depth=1 https://github.com/TEAMBCS/DDOS
cd DDOS
python ddos2.py
```
